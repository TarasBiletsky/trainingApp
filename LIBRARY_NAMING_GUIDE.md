# Project language and naming guide

- Use English for all source code, identifiers, API messages, UI labels, documentation, and newly imported or authored content.
- Use clear domain names (`Workout`, `Exercise`, `SetEntry`) and follow the naming patterns already present in the codebase.
- Exercise library entries shown in the admin UI should prioritize gym equipment: barbells, dumbbells, cables, and machines. Do not include bodyweight-only home-workout entries by default.
- Preserve source, author, and license attribution for imported exercise descriptions and images.
